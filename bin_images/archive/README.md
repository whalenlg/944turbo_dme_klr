# Archived ROM-folder files

Files moved out of `bin_images/dme` and `bin_images/klr` because nothing in
the flow (the simulators, run scripts, bridge, dashboard, installers or CI)
reads them: Intel HEX and partial dumps of the ROM images, an early
disassembly of the 87 KLR (`.asm`, `.opc`, `.sym`, `.csv`, `.d48`), old
assembler tables and the scripts that made them. They are kept here for
reference only. The ROMs the flow uses stay in `bin_images/dme` and
`bin_images/klr`.
